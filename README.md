# COVID-19 Global Impact Dashboard

An interactive **Power BI dashboard** that explores the global impact of COVID-19 across countries and WHO regions using confirmed cases, deaths, recoveries, active cases, and weekly changes.

## Project Overview

This project transforms country-level COVID-19 data into an interactive dashboard designed to make global trends and regional differences easier to understand. The dataset includes **confirmed cases, deaths, recovered cases, active cases, new cases, new deaths, new recoveries, recovery/death rates, weekly changes, and WHO regions**.

## Key Analysis

- Global and country-level COVID-19 case distribution
- Confirmed, recovered, active, and death counts
- New cases, deaths, and recoveries
- Death and recovery rates
- Week-over-week case growth
- Comparison across WHO regions
- Identification of countries with higher case burdens and growth rates

## Dashboard

The project includes an interactive Power BI report for exploring the data through visual summaries and geographic/regional comparisons.

## Files

- `country_wise_latest.csv` — COVID-19 country-level dataset
- `Covid19.pbix` — Power BI dashboard/report
- `Covid19_dashboard.pdf` — exported dashboard for quick viewing

## Tools & Technologies

**Power BI · Data Visualization · Data Analysis · CSV**

## Dataset

The dataset contains country-wise COVID-19 statistics with **15 fields**, including current totals, new weekly activity, percentage-based metrics, and WHO regional classification.

## Objective

The goal of this project is to present COVID-19 data in a clear and interactive format while highlighting differences in disease impact, recovery, mortality, and recent growth across countries and regions.
